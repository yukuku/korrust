# Gid and Rpp single-job retry

Both unchanged sources emitted one candidate class and one official class with the final frozen compiler. This retry uses the same full captured model, source hashes, 164-entry classpath, all 11 plugins and both Compose options, compiler runtime hashes and friend/options context as the original six-source assessment. The input-equivalence record verifies those claims and compares the actual compiler argument arrays; only output directories differ.

This separately authorized run raises the candidate limit from 120 to 600 seconds and reduces jobs 2 to 1 after the real module Gradle build and contract have completed. The original two 120-second timeouts remain intact in the initial report. No dependency, plugin, annotation or option was stripped.

This proves source emission only. Behavior, ABI and Kotlin consumer checks are not run for these per-file probes. Real precompiled sibling/generated app outputs are dependencies for both compilers, so this does not establish a fresh source batch, complete app build, Android runtime, or speedup.
